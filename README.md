## 🔥 Featured Projects

### 🏜️ 1. Off-Road Semantic Segmentation

**Tech:** Python · PyTorch · ResNet34

- Developed an encoder–decoder model for semantic segmentation of off-road terrain.
- Achieved **89.43% IoU**, as reported in the project results.
- Applied data augmentation and GPU-optimized training to improve generalization.

### 🚀 2. Space Station Safety Object Detection

**Tech:** Python · PyTorch · YOLOv8 · OpenCV

- Developed a real-time object detection pipeline for space-station safety scenarios.
- Achieved **95% accuracy** on held-out test data.
- Evaluated detection under varying lighting and noise conditions.

### 🌐 3. AI-Powered Human Trafficking Route Mapping Platform

**Tech:** NLP · spaCy · Transformers · Network Analysis

- Developed an NLP pipeline to analyze dark-web advertisements and phone-record data.
- Applied named entity recognition and relation extraction to map potential trafficking routes.
- Created a domain-specific annotated dataset for transformer-model fine-tuning.

### 🛡️ 4. Government Fraud Detection System

**Tech:** Python · Scikit-learn · Machine Learning

- Implemented Random Forest and Isolation Forest for anomaly detection.
- Used anomaly scoring to identify potentially fraudulent or ghost beneficiaries.
- Achieved **95.6% accuracy**, as reported in the project results.

### 👗 5. ANN Fashion-MNIST Classification

**Tech:** Python · PyTorch · Artificial Neural Networks

- Built a multilayer neural network using ReLU activation, dropout, and the Adam optimizer.
- Achieved **92.8% test accuracy**.
- Analyzed the confusion matrix to investigate class-wise prediction errors.
